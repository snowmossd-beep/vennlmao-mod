MOD SKIN SUNG (iOS · Free Fire MAX) - HUONG DAN CAP NHAT WEB
=============================================================
1) File web (zip "vennlmao-gunmod-web.zip"): giai nen de len repo, ghi de file cung ten:
   - index.html (chi them 1 link CSS, 1 script va 1 muc menu)
   - gun-mod.js, gun-mod.css, gunmod-core.js, fflate.umd.js, lzma-js.min.js
   - guns/catalog.json  (danh sach 68 loai sung, 1.095 skin)
   - guns/img/...       (anh skin, tui dung tu mesh va texture that)

2) Du lieu skin (cac zip "guns-patch-1..N.zip"): giai nen tat ca vao cung thu muc de tao
   guns/patch/<Sung>__<Skin>.patch  (1.025 file, tong khoang 270 MB).
   - Co the chi up mot phan: skin nao khong co file .patch thi nut tai file se bao loi.
   - Neu GitHub Pages cua ban het dung luong, doi CFG.patchBase trong gun-mod.js
     (dong dau) sang URL khac co bat CORS.

3) Cach dung tren web: tab "Mod skin sung" > chon sung > chon skin > chon file bundle goc
   (optionalab_weapon_... trong gameassetbundles cua Free Fire MAX) > chon skin goc dang dung
   > "Tao file mod" > tai file ve va thay vao dung ten file goc.
